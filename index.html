About

Build a holiday itinerary by hand, save it as JSON, load it back to edit, and export a self-contained HTML page or a Markdown file. Everything runs client side. There is no network call and no analytics, and the exported page has no scripts at all.

File format

schema 1
Deliberately simple, so a trip can be generated elsewhere and loaded here to tweak. Unknown fields are dropped on load and every value is treated as plain text.
